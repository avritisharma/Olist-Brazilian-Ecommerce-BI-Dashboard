# Olist Brazilian E-Commerce Business Intelligence Dashboard

## 📌 Project Overview

An interactive Business Intelligence dashboard developed using the Olist Brazilian E-Commerce Dataset.

The project analyses multiple aspects of an e-commerce business, including sales, customers, products, sellers, geographic performance, delivery and payment behaviour.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Star Schema
- Data Cleaning & Transformation
- Data Visualization

## 📊 Dashboard Pages

The dashboard contains eight analytical pages:

1. Executive Overview
2. Sales Performance & Growth
3. Customer Insights
4. Product & Category Performance
5. Geographic Sales Analysis
6. Seller Performance
7. Delivery & Logistics
8. Payment Analysis

## 🔄 Data Preparation

The project involved:

- Handling missing and null values
- Checking duplicates and data consistency
- Correcting data types
- Creating date fields
- Creating a dedicated Date Table
- Establishing table relationships
- Building a Star Schema data model

## 📈 KPIs & DAX

Key measures include:

- Total Sales
- Total Orders
- Total Customers
- Total Products
- Total Sellers
- Average Order Value
- Average Review Score
- Delivery Rate
- Average Delivery Days
- Average Freight Cost
- Total Payment Value
- Running Total Sales
- Monthly Sales Growth
- Year-over-Year Revenue Growth

## 🔍 Business Analysis

The dashboard was used to analyse:

- Sales trends and growth
- Regional sales performance
- Customer behaviour
- Product and category demand
- Seller contribution
- Delivery efficiency
- Freight costs
- Payment behaviour
